# Русификатор Orwell: Ignorance is Strength

Фанатский перевод на русский язык игры [Orwell: Ignorance is Strength](https://store.steampowered.com/app/633060/)
(Osmotic Studios, 2018): тексты, интерфейс, внутриигровые сайты, документы, субтитры подкастов и интро-ролика,
шрифты с кириллицей, по желанию — надписи на картинках.

**Скачать:** [последний релиз](https://github.com/StimDesu/OrwellRU/releases/latest) — установщик
`Orwell_IS_RUS_v*.exe`. Что изменилось в каждой версии — [PATCHNOTES.md](PATCHNOTES.md).

Основа перевода — [esave007/OrwellRU](https://github.com/esave007/OrwellRU) (eSave); этот репозиторий — его
доработка (шрифты, недостающие тексты, вёрстка, даты, картинки, установщик), предложенная автору в
[PR #3](https://github.com/esave007/OrwellRU/pull/3).

## Для игроков

### Какая версия игры нужна

| | |
|---|---|
| Магазин | **только Steam** (AppID 633060) |
| Сборка игры | v1.1.9207.35014 (Unity 5.6.3f1, 32-bit) — актуальная в Steam |
| GOG | **не поддерживается**: это другая сборка с другими файлами данных, установщик на неё не ставится |
| Epic, консоли, пиратские сборки | не поддерживаются |

Русификатор заменяет файлы данных конкретной сборки игры целиком, поэтому на другие сборки его ставить нельзя.
Для версии под GOG нужна актуальная GOG-сборка игры — если она вам нужна и вы можете её предоставить,
напишите в [Issues](https://github.com/StimDesu/OrwellRU/issues).

### Установка

1. Закройте игру.
2. Запустите `Orwell_IS_RUS_v*.exe` — папка Steam-версии находится автоматически (или укажите папку,
   где лежит `Ignorance.exe`).
3. Галочка **«Переведённые надписи на картинках»** (включена по умолчанию) — логотипы сайтов, герб, рекламные
   баннеры, афиша, карты, вывески на фотографиях. Без неё остаётся оригинальная графика; выбор можно поменять,
   запустив установщик ещё раз.
4. Ставится поверх предыдущих версий русификатора.

Перед заменой установщик сохраняет оригинальные файлы игры в `_backup_ru` (существующая копия не перезаписывается).

### Удаление

«Параметры → Приложения» → *Orwell:IS_RUS* — оригинальные файлы возвращаются из `_backup_ru`. Если что-то
пошло не так — «Проверить целостность файлов игры» в Steam.

### Нашли ошибку

Создайте [Issue](https://github.com/StimDesu/OrwellRU/issues): в каком месте игры (эпизод, сайт, документ),
что не так, по возможности — скриншот. Игра пройдена целиком по одной ветке решений; экраны других веток
проверены скриптами, но вживую не все.

### Известные ограничения

- Интерфейс игры внутри интро-ролика остаётся английским (дублируется субтитрами).
- Часть текстов, создаваемых во время игры, на долю секунды показывается крупно, затем ужимается.
- Мелкие надписи, нарисованные внутри фотографий и портретов, не переводились.
- Названия сайтов, ники и хештеги-бренды частично оставлены в оригинале (решение перевода).

## Для разработчиков

### Принципы

- **Файлы игры и её графика в репозиторий не кладутся** (`.gitignore`: `backup/`, `patches/`, `dist/`).
  В репозитории — переводы, скрипты, шрифты (OFL, лицензии в `fonts/google/`). Картинки с переведёнными
  надписями рисуются скриптом `tools/fixes/ui_images.py` из оригинальных текстур при сборке.
- Скрипты работают с файлами Unity через [UnityPy](https://github.com/K0lb3/UnityPy); правки кода игры —
  через Mono.Cecil (`tools/runtime_fix`).
- Сборка **идемпотентна**: всё считается от оригинальных файлов игры (`ORWELL_ORIG`), повторный прогон даёт
  те же байты. После изменений это стоит проверять (`cmp` двух прогонов).
- Многие правки привязаны к id объектов Steam-сборки (`path_id` в `apply_manual.py`), поэтому для другой
  сборки игры (GOG) конвейер нужно переносить, а не просто перезапускать.

### Структура

| Путь | Что там |
|---|---|
| `translated/` | переводы (JSON-батчи), `dll_strings.json` — строки в `Assembly-CSharp.dll` |
| `originals/` | выгруженные английские тексты и инвентари строк |
| `glossary.md` | глоссарий: имена, места, организации |
| `fonts/` | шрифты с кириллицей для генерации SDF-атласов (Ubuntu, LiberationSans, `google/` — семейства сайтов) |
| `tools/*.py` | исходный конвейер мода (eSave): выгрузка строк, патчи `level*`, `resources.assets`, `sharedassets3` |
| `tools/fixes/` | доработки: шрифты (`fix_fonts.py`), недостающие тексты (`apply_loc.py`, `apply_scenes.py`), ручные правки и вёрстка (`apply_manual.py`), картинки (`ui_images.py`, `apply_bundles.py`), тайминги озвучки (`retime_vo.py`) |
| `tools/runtime_fix/` | `OrwellRuFix.dll` — модуль, который работает в игре (ужатие текста, подсветка фрагментов, русская дата), и `build.ps1`, встраивающий его в `Assembly-CSharp.dll` |
| `tools/intro_video/` | русские субтитры и надписи интро-ролика |
| `installer/setup.iss` | установщик (Inno Setup) |
| `FIXES.md` | подробное описание доработок и **порядок сборки** |
| `PATCHNOTES.md` | изменения по версиям |

### Что нужно для сборки

- Steam-версия игры и копия её **оригинальных** файлов `Ignorance_Data` (`level0–4`, `resources.assets`,
  `sharedassets0–4.assets` с `.resS`/`.resource`, `globalgamemanagers*`, `Managed/Assembly-CSharp.dll`,
  `AssetBundles/PCIGN/*`) — в примерах ниже `backup/`.
- Python 3.12+ (проверено на 3.14) и пакеты из `tools/fixes/requirements.txt` (`pip install -r tools/fixes/requirements.txt`).
- Windows: `csc` из .NET Framework 4 и Mono.Cecil ≥ 0.10 — для `tools/runtime_fix/build.ps1`.
- `ffmpeg` в `PATH` — только для пересборки интро-ролика.
- [Inno Setup](https://jrsoftware.org/isinfo.php) 6 или 7 — для установщика.

### Порядок сборки (кратко)

Полные команды и переменные окружения — в разделе «Порядок сборки» в [FIXES.md](FIXES.md).

1. **Перевод мода** (`tools/*.py`, eSave) → переведённые `level1/3/4`, `resources.assets`, `sharedassets3.assets`
   (вход для следующих шагов, `IN`).
2. **Шрифты**: `fix_fonts.py` — SDF-глифы кириллицы во все TMP-шрифты (`sharedassets0/1/3`, `resources.assets`).
3. **Тексты**: `apply_loc.py`, `apply_scenes.py` — недостающие переводы, подгонка текста под свободное место.
4. **Ручные правки**: `apply_manual.py` — вёрстка, высоты страниц, даты, имена, тайминги, картинки в
   `resources.assets`/`sharedassets3.assets`. Собирается дважды: с картинками и с `ORWELL_IMAGES=base` (без них).
5. **Бандлы сайтов**: `apply_bundles.py backup/PCIGN OUT` — картинки в `AssetBundles/PCIGN`.
6. **Код игры**: `tools/runtime_fix/build.ps1` — `OrwellRuFix.dll` и правки `Assembly-CSharp.dll`.
7. **Интро-ролик**: `tools/intro_video/render.py`, `intro_io.py install`.
8. **Установщик**: файлы в `patches/` (вариант без картинок) и `patches/images/` (с картинками, включая
   `AssetBundles/PCIGN/*`), затем
   ```
   "C:\Program Files\Inno Setup 7\ISCC.exe" installer\setup.iss
   ```
   → `dist/Orwell_IS_RUS_v*.exe`. Состав `patches/` — в конце `FIXES.md`.

### Проверка

- Повторный прогон шагов 4–5 должен дать побайтно те же файлы.
- Установщик можно прогнать без окон: `Orwell_IS_RUS_v*.exe /VERYSILENT /TASKS=images /DIR="<папка игры>"`
  (`/TASKS=""` — без картинок), после чего сравнить файлы в игре с `patches/`.
- Перед заменой файлов в своей игре сохраняйте их копию: установщик бережёт только оригиналы.
